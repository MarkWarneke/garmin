LOCAL SNAPSHOT LINK

Only for assistants on this computer.

This option works with the ChatGPT or Claude desktop app on the computer where your Cadence data is saved, with local file access turned on. The assistant then reads the complete snapshot.json and profile.json, including history outside the selected range.

  • The prompt gets a file:// link to the file. In the hosted app, your browser only shares the folder name, so the prompt names that folder instead. Nothing is uploaded.
  • A link alone does not grant access. The assistant must be allowed to read local files.
  • In a web chat, on a phone, or on another computer, the link does not work. Leave the box unchecked; the prompt already contains the data for the selected range, or attach the downloaded JSON.
!

THIS BROWSER IS NOT SUPPORTED YET

Cadence needs a folder on your computer.

The hosted Cadence saves your training history to a folder you choose. That uses a browser feature that phones and tablets, Safari, and Firefox do not offer, so you cannot connect Garmin or sync here.

  • Open Cadence in Chrome or Edge on a desktop or laptop, and choose a data folder there.
  • Or run Cadence locally on your computer; see the project README.
  • You can still look around here, but nothing can be saved.
